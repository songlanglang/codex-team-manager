# codex-team-manager

从自己干到带团队。并行会话检查 + 自动化任务判断 + Skill沉淀时机。

## 安装

```bash
mkdir -p .codex/skills/codex-team-manager
cp SKILL.md .codex/skills/codex-team-manager/SKILL.md
```

或让Codex自己装：
```
帮我安装这个skill：https://github.com/songlanglang/codex-team-manager
```

## 功能

| 模块 | 做什么 |
|---|---|
| 并行检查 | 文件所有权冲突检查、worktree使用时机、读多写少vs写代码并行判断 |
| 自动化判断 | 四条可甩标准 + 四条不可甩清单 + 前置设置检查清单 |
| Skill沉淀 | 判断什么时候该写Skill、AGENTS.md和Skill的分界 |

## 前提

并行和自动化的前提是五件套跑顺了：AGENTS.md写好、验收清单跑通、人工门守住。没跑顺就放手等于拆护栏。
